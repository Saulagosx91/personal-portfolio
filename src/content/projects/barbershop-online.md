## **Barbershop Online**

Aplicación web para la gestión de citas de una barbería. Permite a los clientes reservar citas en línea, elegir barbero y servicios, y al administrador/barbero gestionar la agenda, barberos, servicios y citas."

## Mi rol

Desarrollador Full Stack

## Tecnologías

Frontend: React 19, TypeScript, Vite 8, React Router v7, Tailwind CSS v4, Radix UI, sonner, react-day-picker, date-fns.

Backend: Supabase (Postgres + Auth + Edge Functions), RLS, funciones SQL.

Estado/datos: TanStack Query v5, Zustand v5, Zod v4.

Calidad: ESLint flat config, TypeScript project references, React Compiler.

Agentes de IA: Opencode, GitHub Copilot.
